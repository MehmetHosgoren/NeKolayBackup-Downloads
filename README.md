# NeKolay Backup

**NeKolay Backup**, Windows kullanıcıları için geliştirilen ücretsiz bir yedekleme ve geri yükleme uygulamasıdır.
**NeKolay Backup** is a free backup and restore application developed for Windows users.

## Özellikler

- Kolay yedekleme ve geri yükleme arayüzü
- Restic tabanlı yedekleme altyapısı
- Windows x64 desteği
- Kolay kurulum ve kaldırma
- Ücretsiz kullanım
